## About Me

I'm a full-stack developer based in Tuxpan, Veracruz, México with 6 years of professional experience. I started as an intern and transitioned into a full-time remote developer role, working across backend APIs, frontend interfaces, and — more recently — mobile apps with React Native.

I've worked on a range of projects under NDA: a social platform for sharing reviews of movies and books, a B2B e-commerce system for a uniform supplier, an accounting report generator integrated with QuickBooks, and a school management system that handles finances, CRM, and student records. That variety has pushed me to get comfortable switching between roles — backend, frontend, or both — depending on what the project needs.

Some things I've had the chance to implement along the way: payment gateway integration (Authorize.net), real-time features with WebSockets, background jobs with cron tasks, feature flags for safe production rollouts, and containerized deployments with Docker that I still maintain on a monthly basis.

I work 100% remote and I'm used to owning features end to end. I'm also open to on-site or hybrid arrangements.
